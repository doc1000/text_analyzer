Installation Steps

1

Download and extract the ZIP file

Click the download button above, then extract/unzip the downloaded file to a folder you'll remember.

2

Open Chrome Extensions page

Type chrome://extensions in your address bar and press Enter.

3

Enable Developer Mode

Find the "Developer mode" toggle in the top-right corner and turn it on.

4

Load the extension

Click "Load unpacked" and select the folder where you extracted the extension files.

5

Pin the extension (optional)

Click the puzzle piece icon in Chrome's toolbar, then click the pin icon next to VaultBubble for quick access.

Installation Steps

1

Download and extract the ZIP file

Click the download button above, then extract/unzip the downloaded file to a folder you'll remember.

2

Open Firefox Add-ons Debugging

Type about:debugging in your address bar and press Enter.

3

Go to "This Firefox"

Click "This Firefox" in the left sidebar.

4

Load the extension

Click "Load Temporary Add-on" and select any file inside the extracted extension folder (e.g., manifest.json).

5

Note: Temporary add-on

Firefox will unload this extension when you restart the browser. You'll need to reload it using these steps. Permanent installation will be available once we're listed on Firefox Add-ons.

🚀 Getting Started

🔑

Sign in to your account

Click the VaultBubble icon in your browser toolbar, then click "Sign In." Enter your email and reviewer verification code, and you're in!

📄

Capture a full page

While viewing any webpage, click the VaultBubble icon and choose "Capture Page" to save the entire article or page to your vault.

✨

Capture selected text

Highlight any text on a page, right-click, and select "Save to VaultBubble" to capture just that snippet with context.

🗂️

View your captures

All your captured content appears in the VaultBubble web interface, organized by topics and ready to search. Click the "Reload" button to see your latest captures.
